# student_project_tracking
The Student Project Tracking System (SPTS) is a web-based application developed to simplify and organize the management of academic projects within an educational institution. In traditional project management, project details, submitted documents, progress records, and teacher feedback may be maintained through paper records, spreadsheets, emails, or direct communication. These methods can make it difficult to keep information organized, retrieve project records, and coordinate project activities between students and teachers. To address these challenges, SPTS provides a centralized platform for storing, managing, and accessing project-related information. It helps organize academic project records and reduces dependence on manual record keeping.

The system provides role-based access for three types of users: students, teachers or supervisors, and administrators. Students can submit project details and documents, view, edit, or delete their project records, update project progress, monitor progress history, view project status and teacher feedback, and maintain project-related logsheet entries. Teachers or supervisors can view and review submitted student projects, provide feedback, update project status, and view logsheet records of assigned students. Project statuses include Submitted, Approved, In Progress, Completed, and Rejected. Administrators can manage user accounts, add teacher accounts, assign supervisors to students, and access user and project information. The application is developed using HTML and CSS for the user interface, JavaScript for client-side interaction, PHP for server-side processing, and MySQL for database management. XAMPP is used as the local server environment, while phpMyAdmin is used to manage the database. Overall, SPTS provides an organized platform for managing academic project information, monitoring student progress, maintaining logsheet records, and supporting communication and review between students and teachers.
